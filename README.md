Vibe Coding Project - INSIDE 
This game has the concept of you becoming a Hacker. In this simple game, you will be given 2 choices: Black hat and White hat.  
This game is made user-friendly; if you are not used to the terminal, you can use the "Desktop" mode which has a UI display.  
The game mimics how commands work in the terminal.  
Type "help" in the terminal when the game is running.


How to Run WEB base 
1. NPM install 
2. NPM run Dev
